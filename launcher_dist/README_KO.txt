나만의리니지 접속기 사용법
==========================

1) 이 압축 안의 파일을 전부 리니지 클라이언트 폴더(TW13081901.bin 이 있는 폴더)에 복사
   - 나만의리니지.exe, list.txt, config.ini, skins 폴더, *.flag 파일

2) Tailscale 이 켜져 있는지 확인 (작업표시줄 아이콘 → Connected)

3) 나만의리니지.exe 더블클릭
   - 서버 불이 초록색이면 [게임 시작]
   - 창 크기 800x600 / 1200x900 / 1600x1200 선택 가능

문제가 생기면
 - "WebView2" 관련 오류: https://go.microsoft.com/fwlink/p/?LinkId=2124703 설치
 - 기존 Login.exe 는 그대로 남아 있으니 언제든 예전 방식으로 접속 가능
 - 되돌리기: 위에서 복사한 파일만 삭제하면 끝
